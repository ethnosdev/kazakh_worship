[Em]Қуаныңдар [Am]достарым, [Em]мадақтаңдар Тәңірді.
[Em]/ Иса Ұлын жерге жіберіп,
[Am]Сыйлаған мәңгі [Em]өмірді. / 2p
2. Шаттаныңдар бауырлар,
Шырқатып әсем әнменен,
/ Ашылды бізге құпия,
Ата-бабаң білмеген. / 2p
3. Тамаша бөленсін
Табиғат біткен сүйсініп,
/ Исаның сөзін естісін
Барлық халық құлшынып. / 2p
4. Ақиқатты танысын
Түнектегі жұртшылық.
/ Ашылсын бәрі перденің,
Арайлап атсын күн шығып. / 2p
5. Оян бауыр, халғыма.
Жігеріңе жігер қос.
/ Құдайдың берген бұйрығын
Орындамай жүрме бос. / 2p
