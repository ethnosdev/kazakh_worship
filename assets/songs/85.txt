{language: kk}

[Am][E]Сүйіспеншілікпен әндетіп,
Сенімде бірге [Am]жүруші ек.
[Dm]/ [Am]Асуы биік жолдарда,
[E]Боранға [Am]қарсы тұрушы ек. / 2р
2. Аз ғана еңбек етсек те,
От болып жанып тұрушы ек.
/ Түнгі аспанға қарап біз
Алысқа, көзді тігуші ек. / 2р
3. Бізді қорқытқан сөздерді,
Тайсалмай қарсы алушы ек.
/ Құдайдың сөзін орындап,
Дүниеде таза жүруші ек. / 2р
4. Шуақты қымбат жұмаққа,
Жырлай біз бірге барамыз.
/ Қайғысы, мұны жоқ жерде,
Мәңгілік жасап қаламыз. / 2р
Мадақтау
Жан-тәніммен Жаратқан Иені мадақтаймын,
Шын жүректен қасиетті атын ардақтаймын.
Жан-тәніммен Жаратқан Иені мадақтаймын,
Маған көп жақсылық жасағанын ұмытпаймын.
Ол бар күнәларымды кешіріп,
Дерттерімнің бәрін сауықтырады.
- Забур жырлары 102:1-3
