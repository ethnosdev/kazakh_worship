[Am]Мен тоқтап, біраз көз салсам,
[F][G]Өмірдің өткен [C]жолына,
/ [Am]Әр күнә [Dm]келіп ойыма,
[E7]Батады [Am]менің жаныма. / 2р

2. Мен қылған қанша күнә бар,
Естісе адам ұялар,
/ Шындықты айтсам Құдайға,
Күнәдан мені құтқарар. / 2р

3. Күнәмді алып мойныма,
Бас иіп Тәңір алдында,
/ Өтініп, тәубе қылайын,
Апаршы өмір жолына. / 2р

4. Шындықты көрдім жолыңнан,
Өзгерткен менің ойымды,
/ Құтқарып алшы Тәңірім,
Ұсынып, созам қолымды. / 2р

5. Өмірімді Саған арнайын,
Жүректе Сені сақтайын,
/ Дүниеге айтып шындықты,
Мәңгілік Сені даңқтайын. / 2р
